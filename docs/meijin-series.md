# 名人詰将棋百番の構成（2026-11-27 実見）

この本は一人の作品集ではなく、**代ごとの「詰将棋図式」を集めたもの**で、
各代の番号が **1 から振り直される**。頁の見出しに「初代 宗桂作詰将棋図式」
「第二代 宗古作詰将棋図式」のように代と作者が印刷されている。

## R0000010 で確認したこと

| 頁 | 見出し | 題簽 |
|---|---|---|
| 右 | 初代 宗桂作詰将棋図式 | 十番 |
| 左 | 第二代 宗古作詰将棋図式 | **一番** |

左頁の題簽は「一番」で、本文も「第三代将棋所」など代の変遷を述べる。
つまり左頁の盤は **第二代の1番**であって、通し番号の十一番ではない。

## draft への影響

`collections/taisho/meijin/drafts/011.json` は source を
「R0000010左 十一番」としているが、この葉の左頁は第二代の一番。
**代ごとの番号と通し番号が混ざっている可能性**があり、未読83題の source は
「代・作者・その代の番号」で持ち直す必要がある。

盤面の読み取り（罫線実測＋升ごとの切出し）は有効なので、
まず source の同定をやり直してから盤面を読む。
