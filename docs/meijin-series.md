# 名人詰将棋百番の構成（2026-11-27 実見）

この本は一人の作品集ではなく、**代ごとの「詰将棋図式」を集めたもの**で、
各頁の見出しに「初代 宗桂作詰将棋図式」「第二代 宗古作詰将棋図式」のように
代と作者が印刷されている（R0000010 の左右で見出しが変わるのを確認）。

## 番号は通しのまま（2026-11-27 時点の判断）

- 各葉の題簽は R0000005左=一番 から、右頁・左頁の順に 2,3,4…と**連続**している。
- R0000010 の左頁に「一番」に見える小字があったが、原寸で切り直すと題簽の位置を
  特定できず、**「十一番」の 十 を小さく書いたもの**と見るのが自然。
- したがって draft の通し番号（001〜100）は維持する。

## 未確認のこと

- 代の切り替わりが正確にどの題か（見出しは R0000010 で第二代になる）。
- 各代の作品数と、通し番号との対応。
- 題簽の「十」の書き方（小さく上に書くのか、同じ大きさか）。

盤面の読み取り（罫線実測＋升ごとの切出し）は source の同定と独立に進められる。

## 巻の構成（2026-11-27・IIIF manifest）

- PID 935873「名人詰将棋百番」（将棋新報社編・大野万歳館・大正1年）は **1巻72コマ**。
- 100題は R0000005〜R0000055 の約51葉に2題ずつ並ぶ（百番 = R0000055右）。
- **解答編は無い**（残りのコマは前付・奥付）。したがって初手や盤の向きを
  解答から決めることはできない。
- 盤の向きは、各図の「王（唯一）」と「端段の香（行き所のない駒）」で較正する。
  図ごとに上下が違うため、頁をまたいで規則を流用しない。

## 大橋家第五代宗桂の図式（2026-11-27 実見）

- R0000020左 = **一番**（通し31番）・R0000021右 = **二番**（32番）・R0000021左 = **三番**（33番）。
  各図の右に「大橋家 第五代 宗桂 作詰将棋図式」の題簽、その左に「一／二／三 番」の小字。
- 一番（31）は1手詰（と4五→3五）、二番（32）も1手詰（2五桂打）。導入部は短手数。
- 三番（33）は20枚・持駒 銀。盤面は確定したが側の自由度が残り、5手・7手では詰まない（保留）。
- 題簽の「第○代」は代ごとの区切りではなく**作者の家と代**を示す。頁の式（docs/ndl-collation.md §2.3）は
  この3図で整合する（L→次葉のR→同葉のL の順に読む）。
