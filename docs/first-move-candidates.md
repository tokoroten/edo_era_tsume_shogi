# 未検証の初手候補（seimyo）

各題の玉に王手になる記録済み列頭。`（確定済み: N番）` は同じ手が
既に確定題の初手になっている列頭。1つの列頭は1題のものなので、
その列頭が未検証題の初手かは確定題との取り合いになる（複数番は
同じ手の題が複数あり、列頭の帰属が一意でないことを示す）。
候補が1つでも、その列頭が他の未検証題の候補にもなっていれば未決。
0なら列頭が未記録。
