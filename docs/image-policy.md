# 画像掲載方針（NDLスキャンのウェブサイト掲載可否）

調査日: 2026-09-23。根拠は国立国会図書館の公式ページのみ
（`dl.ndl.go.jp/ja`「デジタルコレクションの画像の二次利用について」、
`www.ndl.go.jp/use/reproduction`「ウェブサイトからのコンテンツの転載」、
`www.ndl.go.jp/help/utilizing`「よくあるご質問」、
`www.ndl.go.jp/copy/publication`「所蔵資料の二次利用」、
各PIDのIIIF manifest `license`/`Access Restrictions`）。
個人サイト・非政府団体サイトは参照していない。

## 結論

- **「インターネット公開（保護期間満了）」の画像は、商用含め無償・申請不要で
  自由に利用できる**（転載＝インターネット・ホームページ等への掲載を含む）。
  本プロジェクトの4単位（PID `861197`/`861198`/`861193`/`861194`、
  manifest `Access Restrictions: PDM`）はこの条件を満たす。
  すなわち**現画像のウェブサイト掲載はライセンス上問題ない**。
- ただし以下の遵守事項がある（§§1–2）。無双・極妙のように
  インターネット公開デジタルがない資料の画像は掲載対象外（§3）。

## 1. 遵守事項（掲載時に必須）

1. **画像単位の公開範囲確認**: 書誌単位ではなく、転載したい画像を表示して
   個々の書誌情報の公開範囲が「インターネット公開（保護期間満了）」である
   ことを確認する（`use/reproduction` §3 手順②④）。本プロジェクトでは
   掲載canvasごとに `docs/` の台帳（PID/RID）に確認結果を残すこと。
2. **出典の明示**（協力依頼）: 画像付近に「国立国会図書館デジタルコレクションより」
   等と記載する。巻末一括ではなく付近記載が望ましい（`help/utilizing` Q&A）。
3. **転載であることの明示**: 利用した画面がNDLウェブサイトからの転載である
   ことを明示する（`use/reproduction`）。
4. **人格権・プライバシーへの配慮**: 保護期間満了でも著作者人格権等に配慮する。
   江戸期詰将棋図面では実害想定は低いが定型として確認する。
5. **構成の丸ごと再現の禁止**: 電子展示会の例示に準じ、NDL側の構成をそのまま
   再現するような利用は避け、問題単位の抜粋＋自前の解説・検証情報と組み合わせる
   こと（本プロジェクトのdraftsページはこの形）。
6. **「ご注意とお願い」の一読**: 公開前に `use/reproduction` §6 を読むこと。

## 2. 掲載方式（ホットリンク禁止・自前ホスト）

- NDLのIIIF URLへの**直リンク（ホットリンク）は行わない**。
  理由: NDLサーバへの負荷・IIIF API利用条件（manifest `license` 指針）への配慮、
  および本プロジェクトで実測したレート制限（HTTP 403。
  `docs/data-acquisition.md` §5）。
- 方式: 公開範囲を確認したcanvasの必要域を切り抜き、リポジトリ外で管理した
  派生画像を自前ホスト（GitHub Pages）する。派生画像にも §1 の出典表示を付す。
- 画像のライセンス表示に注意: NDLスキャン画像自体は Public Domain であり、
  本プロジェクトの **CC0-1.0（転記データ）やMIT（コード）と混同しない**。
  ページ上で「原画像: Public Domain（NDLデジタルコレクションより転載）／
  転記データ: CC0-1.0」と区別表示すること。

## 3. 掲載対象外

- インターネット公開デジタルがない資料（無双 `000001281469`、
  極妙 `000007296776`/`000007296777`）の画像は掲載しない。
  館内限定・送信限定・許諾/裁定の画像は権利者許諾なしに掲載しない。
- `needs_manual_review` の表示義務は画像掲載と独立に維持する
  （画像を載せても照合済みを意味しない）。
