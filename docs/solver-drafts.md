## 検証を解禁する条件

1. 当該 draft の盤面 `?` が 0 になる（原寸照合・先後確定）。
2. `tools/validate.py --draft` が盤面依存チェックを実行できる状態になる
   （`gap: board-dependent checks skipped` が出ない）。
3. `validate.py --draft` が `illegal position` gap を出さないこと
   （2026-11-17 追加。手番側でない玉が王手されている SFEN を検出する。
   076 がこれに該当し、solver に渡すと無意味な MATE が返る）。
4. そのうえで `probe --max-ply N`（N≥11）を実行し、詰み／不詰を記録してから
   `intended_solution_usi` / `solution_usi` を確定する。初手が複数出た場合は
   一意解検証に失敗したものとして扱い、図面の再読に戻す。

## 「一意な手順」の試みは撤回（2026-11-25）

7手以内の詰み筋を列挙する自作ツールで「一意な解」を探したが、**そのツールは詰みを
証明していなかった**。全手順を「後手の応手」で分岐させず、1本の応手だけを辿って
「詰み」に到達した順序を記録していたため、**後手が別の応手で逃げる手も「詰み」と数えて
いた**（例: 精妙四番 7a7b は 8b8a で逃げられる）。

したがって次の主張は撤回する:

- 精妙二十四番の「1手詰」→ 打ち歩詰め（反則）の誤り。
- 精妙六十三・七十八番、貫珠三十五番の「一意な9手/7手詰」→ 証明になっていない。

**現在の権威は次の2つだけ**:

1. `tsume-solver` の MATE（AND/OR 探索の証明）。
2. 本ドキュメント冒頭の「現在有効な証明」表（盤面SFENつき）。

`tools/mate_lines.py` は **AND/OR 証明器に書き換えた**（先手の手は「全ての後手応手に
対して詰む」ものだけを採用し、後手は全応手を検査する）。書き換え後は
ソルバーと一致する（精妙六十七番は `金35 玉35 金打36` の1本、精妙四番は5手以内に
強制手なし、貫珠三十四番は5手以内の強制初手が `金打25` の1本）。

全問の再走査は時間がかかるため、結果は別途追記する。

## 詰みの規則が2つある（2026-11-25）

このプロジェクトには**詰みの定義が2つ**あり、両者は別物である。混同すると
「ソルバーは詰まないと言うが本の手順は詰む」という矛盾が起きる。

| 規則 | 後手が打てる駒 | 使う道具 | 用途 |
|---|---|---|---|
| **本の規則**（持駒のみ） | 持駒だけ | `replay_line.strict_mate` / `tools/mate_lines.py` | 江戸の本の手順を読む・検証する |
| **データセットの規則**（駒箱） | 盤上・持駒以外の**未使用の全駒** | `validate.is_mate` / `tsume-solver` | 提出レコードの詰み保証 |

実例（貫珠六番の本の5手を並べた最終局面）:

- 後手の持駒: 空
- 後手の駒箱: 歩15・香2・桂1・金3・角1・飛2
- `strict_mate`（本の規則）= **詰み**
- `validate.is_mate`（駒箱）= **詰みではない**（歩を打って延命できる）

したがって:

- `tsume-solver` の REFUTED は「**駒箱規則で**詰まない」の意味であり、本の手順が
  間違いという意味ではない。

## 「9〜11手以内に詰みなし」は異常ではない（2026-11-25）

完成盤面の多くが 9〜11手以内に詰まないという結果が出る。これは盤面の誤りではなく、
**この2書の作が長い**ことの反映と考えられる。

根拠:

- 貫珠三十四番の印字手順は 12手まで盤面で検証でき、なお続く（15手以上）。
- 本の手順列はどれも長く（1列に10〜20手）、5〜7手で終わる列は少ない。
- 精妙の完成盤面21題では、9手以内に強制詰みがあるのは2題だけ。
- 追加で調べた 精妙七十八・五十七、貫珠十二 も 11手以内は厳密に「詰みなし」。

- `REFUTED (max-ply 9)` は「盤面が誤り」の証拠にならない。**長手数の作**として扱う。

- 盤面の正しさは「駒数・二歩・死に駒・王手の成立・手順の再生」で見る方が確実。

この interpretive な修正により、以前「9手以内に詰まないので盤面が怪しい」と保留した題の
扱いを改める（盤面の採用判断には使わない）。
