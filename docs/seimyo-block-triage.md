# 精妙 上巻: ブロック17題のトリアージ

作成日: 2026-11-25。目的: 「盤面は読めているが列頭の初手と整合しない」17題について、
下巻（詰手。NDL PID `861217`）のどのコマを読めばよいか・何を確認すれば解除できるかを一覧化する。
方針とデータ規約は `docs/data-policy.md`・`docs/validation.md` に従う。

## 0. 方法（2026-11-25 に確立・3題で成功）

1. 下巻の該当コマを取得し、題簽（「N番」）の**直左の列**を原寸〜高倍率で読む。
2. その列頭（駒名＋行き先2字、`同`/`成`/`打` の小字）を初手の**仮説**とする。
3. 盤面（3モデル多数決で読んだ升）で、その手が**合法かつ王手**になるかを機械確認する。
4. `tools/leaf_heads.py <RID> --range A B` で「列頭→王手になる題」の一意対応を確認する。
5. 3が成立したときのみ初手を差し替え、`docs/seimyo-column-heads.json` の列頭も
   「題簽直左の列」に付け替える（元の列は `problem: null` に戻す）。

成功例: 五十二番（六六銀）/ 五十七番（三九桂=桂打9三）/ 六十一番（七三歩成）。
いずれも**盤面ではなく列頭の帰属**が原因だった。
失敗例: 九十二番は 1三 の1升に局所化（列帰属は正しい）。五十三番は直左列が王手不成立。

## 2. leaf_heads による事前照合（2026-11-25 実行）

`python tools/leaf_heads.py <RID> --range A B` の「per problem」出力（未読升を空として判定するため過大評価に注意）。

- **R4 (7–10)**: 7 と 9 が同一の3候補（五一金・二一龍 など）を共有 → 曖昧。8/10 は一意。
- **R5 (11–14)**: **14 は一意**（二六金）で王手成立 → 衝突は盤面側（行き先6二の升）に局所化。
- **R9 (29–32)**: 29 は2候補・30 は2候補（いずれも 二一龍 を含む）→ 曖昧。
- **R10 (33–37)**: 35 は2候補（四九龍 を含む）、**37 は一意**（三七龍）で王手成立 → 37 も盤面側の疑い。
- **R24 (90–93)**: 90=二九馬 / 91=三五銀成 / 92=六一飛 / 93=三二飛 が一意 → 92/93 の帰属は正しい。

所見: 「列頭が見つからない」型（7/9/29/30）と「列頭は正しく盤面の1升が怪しい」型
（14/37/92）に二分できる。後者は升単位の原寸再読で解除できる見込みが高い。

## 4. 注意

- 列頭の読みが王手になっても、**詰みまで成立するとは限らない**（#061 は15手以内 REFUTED、21手では UNKNOWN）。
- 盤面の欠陥と列頭の誤帰属は症状が似る。判定は必ず「合法手か」「王手か」の機械確認を経由する。
- `leaf_heads` は未読升を空とみなすため「checks」判定は過大。盤面が埋まるほど判定は厳しくなる。
