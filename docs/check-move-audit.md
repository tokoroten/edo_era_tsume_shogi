# 初手の王手全列挙による監査（2026-11-25）

詰将棋は**必ず王手で始まる**。したがって「盤面上で合法な王手をすべて列挙する」ことは、
盤面の翻刻と列頭（詰手の初手）の両方に対する独立した制約になる。この監査は
`tools/check_moves.py` で機械的に再現できる。

```
python tools/check_moves.py                 # 両コレクション・? が6升以下
python tools/check_moves.py seimyo --max-q 9 --only-fail
python tools/check_moves.py --md --moves    # 全王手を Markdown 表で
```

実装上の注意（過去に誤判定を生んだ点）:

- **成駒を動かすときは成りのまま**。と金を「と→歩」に戻すと王手が消える。
- **打ち歩は二歩・死に升・打ち歩詰めを除外**。除外しないと「唯一の王手」が幻になる。
- `?` は空き升として扱うので、王手の**個数は上界**。ただし着手元・経路・着地点が
  `?` に触れない王手は、`?` が何であっても合法（表中の `solid`）。

## 集計

判定は3種類:

| 判定 | 意味 |
|---|---|
| `head-ok` | 記録された初手（駒種・行き先・成り）が合法な王手として存在する |
| `dest-ok` | 記録された**行き先**には王手になる手があるが、記録された**駒種**では届かない |
| `dest-absent` | 記録された行き先**自体**が、その盤面の王手の升ではない |

| コレクション | `?` の範囲 | head-ok | dest-ok | dest-absent |
|---|---|---|---|---|
| 精妙 | 0–4 | 58 | 6 | 18 |
| 精妙 | 5–9 | 3 | 1 | 4 |
| 精妙 | 10–14 | 0 | 0 | 2 |
| 精妙 | 15–19 | 0 | 2 | 4 |
| 精妙 | 20–24 | 0 | 0 | 2 |
| **精妙 計** | | **61** | **9** | **30** |
| 貫珠 | 0–4 | 34 | 4 | 4 |
| 貫珠 | 5–9 | 4 | 0 | 0 |
| 貫珠 | 10–14 | 0 | 0 | 1 |
| 貫珠 | 20–24 | 1 | 0 | 2 |
| **貫珠 計** | | **39** | **4** | **7** |

`?` の多い盤面（15升以上）は王手の列挙自体が信用できないため、判定は暫定。
`?` が5升以下の盤面では列挙はほぼ確定で、**そこでの不一致は盤面か列頭のどちらかが誤り**である。

## 不一致の原因は3つに分かれる

1. **駒種の誤読**（`dest-ok`、行き先は正しい）
   - 四十三番: 記録 `一八香` → 盤面では2九の銀だけが1八へ届く ⇒ `一八銀` に訂正。
   - 三十九番: 記録 `四二香` → 1四の飛だけが2四へ届く ⇒ `四二飛` に訂正。
2. **列の帰属の誤り**（`dest-absent`、行き先が王手の升でない）
   - 三十八・五十六（`?`=0 の完成盤面でさえ一致しない）ほか。
3. **盤面の誤り**（合法な王手が1つも無い）
   - 十八番: 唯一の候補 `P*8f` は**二歩**（8九に先手歩）。他に王手が無く、盤面が誤りと確定。
   - 七十五番: 合法な王手が0。盤面が誤り（または大きく欠落）。

## ソルバーによる裁定（新しい判定法）

「合法な王手だが、詰まない」列頭は、**ソルバーで反証できる**。詰将棋の初手は詰みに
至る手でなければならないので、反証された手は初手ではない。

七十二番（`?`=2）が最初の適用例:

| 手 | ソルバー | 備考 |
|---|---|---|
| 二七と（記録列頭、6三のと→7二） | 1手で反証 | 8一玉が7二のとを取る |
| **八二歩打** | **9手詰**（nodes 8,065 / exhaustive） | 採用 |

初手を `八二歩打` に差し替え、`二七と` の列は `verified: false` とした
（`docs/seimyo-transcription.md` 「七十二番: 初手のソルバー裁定」）。

この方法は `dest-ok` / `dest-absent` の残件にもそのまま使える。盤面が十分に読めていて
（`?` が少ない）、ソルバーが詰みを返せば、その初手が答えであり、列頭の食い違いは
列の帰属の問題だと確定する。逆に詰みが返らない場合は、盤面側の誤りを疑う。

## 次にやること

- `?` が5升以下で `dest-ok` / `dest-absent` の残件にソルバーを当てる
  （詰みが出れば初手確定、出なければ盤面再読）。
- 現在の残件は `docs/open-issues.json` に候補SFENつきで構造化してある。

## 成駒の比較で一度誤集計した（2026-11-25）

`promoted: true` は「その手で成る」ではなく「駒が成っている」を意味するため、

`lands_promoted()`（`promotes_now or src_promoted`）で比較し、回帰テストで固定した。

## なぜ候補盤面を採用できないか（データ構造上の理由）

初手レコードは盤面と対になっている:

- `docs/*-first-moves.json` の各行は 1題=1初手。
- `docs/first-move-status.md` の行集合は JSON と一致していなければならない（テスト）。
- `tests/run_tests.py::test_first_moves_check_the_king` は、初手の駒をその升に置けば
  王手になることを要求する。

したがって「盤面だけ差し替えて初手は未決」という状態を表現できない。盤面を採用すると
初手も同時に確定させる必要があり、列頭が王手の集合に入らない題では採用できない。
**列頭を `unassigned` にできるデータ構造**（例: `head_unassigned: true` と
`best_check` 候補）を先に用意するのが、残り133升を活かすための前提条件である。

## 貫珠 十八番の追試

原寸（900px）で列頭を再確認し、**一三銀成** の `銀` と `成` を読み取った（`角` ではない）。
盤面の `?` は4二の1升だけで、銀を4二に置けば 3一成 が王手になる（他に候補なし）。
しかし完成させた盤面は11手以内に詰みが無い（厳密）。列頭と盤面の両方が読めているのに
詰まないため、**どちらかを採用するには原本の手順列が必要**という結論になった。

## 解決: `head_unassigned`（2026-11-25）

上の「データ構造上の理由」は解消した。初手レコードに **`head_unassigned: true`** を
持たせ、盤面だけを採用できるようにした。

- `docs/*-first-moves.json`: 印字された列頭（`raw`/`piece`/`file`/`rank`）は残し、
  `head_unassigned: true` を付ける。`board_q`・`confidence` は盤面に合わせる。
- `tests/run_tests.py`: 王手検証・成り・打ち歩・自駒の4テストはこの印の行を飛ばす
  （代わりに `test_board_q_matches_draft` が盤面の品質を検査する）。
- `tools/head_check.py`: 状態 `UNASSIGNED` を返す。
- `docs/first-move-status.md`: 初手欄を「未決（列頭 …）」とし、件数は「検証済み 47/50・96/100」。

## 成りの列頭は「成り先」を指す（2026-11-25 の検証）

精妙九十七番の列頭 `三五角成` は、盤上の角の位置 5三 と一致するが**成り先ではない**
（5三の角は 4二/6二 へ成って王手）。そこで「成りの列頭は成る駒の位置を指す」という
仮説を全題で検査した。

- 成りを含む列頭: 精妙21・貫珠8。
- 仮説に合う（印字2字が、成って王手になる未成り駒の位置と一致）: 精妙1・貫珠0。
- その1題（精妙六十二 `四三角成`）も、もう一方の読み `3四` が実際の成り先で説明できる。

したがって列頭の2字は**成り先**を指すのが原則で、九十七番だけが例外（原典の字か、
こちらの読みのどちらかが誤り）。盤面は2モデル完全一致なので採用し、初手は未決のまま残した。

## 駒数による違反検出（2026-11-25）

将棋の駒は1組しかない（歩18・香4・桂4・銀4・金4・角2・飛2・玉2）。成駒は元の種で数え、
持駒も含める。したがって**上限を超える盤面は、モデルが何個一致していても誤り**である。
`tools/material_audit.py` がこれを検査する。

```
python tools/material_audit.py          # 両コレクション
python tools/material_audit.py --md
```

検出結果:

| コレクション | 題 | `?` | 超過 |
|---|---|---|---|
| 貫珠 | 八 | 0 | ~~金 6~~ 訂正済み（全=成銀） |
| 貫珠 | 三十 | 1 | 金 5 |
| 貫珠 | 五十 | 1 | 金 5 |
| 精妙 | 九十六 | ~~5~~ 3 | ~~金 5~~ 訂正済み |

**貫珠八番は `?`=0 の完成盤面で金が6枚**あり、複数モデルの一致と初手検証を通過していても
誤りである。金1枚が別の駒（香・銀など）の読み違いだと確定できる。これは
「一致＝正しい」ではないことを示す、初の機械的な反例である。

四題とも金の過剰なので、疑うべきは金の字（あるいは金と紛らわしい香・銀）。原本で
金の升を確認すれば直る見込みが高い。`docs/open-issues.json` に記録した。

### 貫珠八番の追跡（持駒を原寸確認）

上限超過4題のうち、貫珠八番は `?`=0 の完成盤面なので、どこが誤りかを絞り込んだ。

- 盤下の持駒を 1400px で読むと **飛金金桂**（飛1・金2・桂1）で、記録と一致した。
- 盤上の先手金は 1一 と 7五 の2枚。持駒2＋盤上2＝4で、すでに上限。
- よって**後手の金 1三・5四 は金ではない**。この2升が誤りと確定した（銀・香などの候補）。

「持駒を先に確定させると、盤上のどの駒が誤りかが絞れる」という手順は他の3題にも使える。

### 決着: 貫珠八番の「金」は 全（成銀）だった

持駒を確定したうえで盤面の金の升を原寸で見ると、1一 と 1三 の字は **全** であった。
将棋の略字で **全 = 成銀**（銀の成駒）であり、金ではない。モデルは 全 を 金 と読んでいた。

- 1一 = 先手の成銀 (+S)、1三 = 後手の成銀 (+s) に訂正。
- 金は「5四の後手金・7五の先手金・持駒2」で**ちょうど4枚**。駒数違反が解消。
- 玉に王手は掛からず（1一の成銀は2三玉に届かない）、初手 四二金 (G*24) も王手のまま。

**教訓**: `全` は `金` と紛らわしく、モデルは金に寄せる。金が多い盤面はまず 全（成銀）を疑う。
同様に `と`(成歩)・`圭`(成桂)・`杏`(成香) も、成っていない駒との混同に注意する。

### 精妙九十六番: 成駒の略字をまとめて訂正

同じ手法（持駒→駒数→原寸）で、1段目を読み直すと4枚が成駒の略字だった。

| 升 | 旧 | 新 | 字 |
|---|---|---|---|
| 6一 | G | +s（後手成銀） | 全 |
| 4一 | ? | +R（先手龍） | 龍 |
| 3一 | ? | +P（先手と） | と |
| 2一 | l | +l（後手成香） | 杏 |

訂正後: 金は4枚ちょうど、先手の王手なし、`?` は 5→3。
そして**列頭 一六龍 が 4一→6一 の龍の手として王手**（`+R61<-41`）になり、初手も確定した。
成駒の略字（全・杏・圭・と）を素の駒として読むと、駒数・利き・初手のすべてが狂う。

## 死に駒の検査（2026-11-25）

成駒を素の駒と読み違えると、**動けない升に素の駒が残る**ことがある。次はすべて反則:

- 先手の歩・香が1段目、後手の歩・香が9段目
- 先手の桂が1〜2段目、後手の桂が8〜9段目

`tools/material_audit.py` の `dead_pieces()` がこれを検出し、`adopt_board.py` は
該当する SFEN の採用を拒否する。全150題の走査では **精妙七十五番** の 6九 の後手香
（香のままでは一度も動けない）が該当した。`+l`（成香）に直しても合法な王手は現れないため、
この題は盤面全体の再読が必要（`docs/open-issues.json`）。

成駒の略字（全・圭・杏・と）を素の駒として読む誤りは、
**駒数（金が増える）→ 死に駒（動けない升に残る）→ 利き（成駒の動き）** の3方向で検出できる。

### 二歩の裁定を試みた結果（2026-11-25）

二歩の2枚のうち片方をと金に変えて、ソルバーで詰みを比べた。

| 題 | 変換A | 変換B | 判定 |
|---|---|---|---|
| 貫珠 二十二 | MATE 3手 | MATE 3手 | **どちらでも同じ3手詰** |
| 貫珠 三十八 | 詰みなし（7手・厳密） | 詰みなし（7手・厳密） | 区別できない |

二十二番は二歩の升（9筋）が**解の手順に無関係**なので、どちらに直しても同じ3手詰になる。
盤面としては合法化できるが、どちらが正しいかは字形でしか決まらない。
三十八番はどちらでも詰まないので、盤面の別の所が誤り。

「違反升が解に無関係なら、ソルバーは裁定できない」— これは材料（駒数）の裁定との違いである。

## 唯一の王手で初手が決まる題（2026-11-25 再走査）

盤面を完成させた後、列頭が着手不能な題を再走査した。合法な王手が**ちょうど1手**で、
その着手元・経路・着地点が `?` に触れない（= `?` が何であっても成立する）題は、初手が確定する。

| 題 | `?` | 唯一の王手 | 印字列頭 | 扱い |
|---|---|---|---|---|
| 精妙 七十三 | 3 | 二五銀（1四→2五） | 六二馬 | 初手に採用、列は未割当 |
| 貫珠 十七 | 1 | 八二角成（9三→8二） | 四八桂 | 初手に採用、列は未割当 |

いずれも印字列頭は盤上・持駒に移動元が無い。`?` が任意でも成立する王手なので、
「他の王手が `?` に隠れている」可能性は残るが、詰将棋の初手は王手である以上、
この1手が最も確からしい。四十二・九・四十八番と同じ判断基準。

## 「動かせる升が1つ」でも採用しなかった例（2026-11-25）

## 未決列頭の読み直し（2026-11-25）

未決35題（精妙）について、印字された2字と駒種を**両順序 × 紛らわしい駒種**で
盤面に当て直した（例: 金↔銀↔香、飛↔龍、角↔馬、成/不成）。

結果: **31題はどの読みでも王手にならない**。残り4題に候補があり、うち2題を確定した。

| 題 | 印字 | 確定した読み | 根拠 |
|---|---|---|---|
| 九十八 | 三二金 | **三二銀** | 2三へ王手になるのは3二の銀だけ（金は届かない） |
| 五十一 | 二三飛 | **三二飛成** | 2字を筋→段に読むと3二。成らないと王手にならない |

残る2題（四十四・五十八）は候補が複数あり、駒種を決められない（四十四は 成香 と と金 の両方、
五十八は候補が盤面上の別の駒）。原本の字を見る必要がある。

**31題がどの読みでも駒まない**ということは、原因は単純な駒種の誤読ではなく、
盤面（未読の升）か列の帰属そのものにある。`docs/seimyo-head-fit.md` の候補表と合わせて

## 3モデル目で割れを解消する（2026-11-25）

2モデル (Opus/Codex) が対立した升に、**3つ目のモデル (Claude Sonnet)** を同じ頁・同じ
指示で読ませた。1升ずつ多数決できる。

**精妙三十番**の結果:

| 升 | Opus | Codex | Sonnet | 判定 |
|---|---|---|---|---|
| 1四 | 駒なし | +p（後手と金） | **+p** | 2票で +p を採用 |
| 4八 | g（金） | l（香） | **p（歩）** | 3者3様、保留 |

1四 は王手・駒数・二歩・死に駒のいずれにも触れず、埋めても合法（`?` 2→1）。

3者3様の 4八 は、多数決が使えないので保留した。**「3モデルで割れたら保留」** が原則で、
2対1のときだけ採用する。

### 3モデル目の限界: 持駒を捏造することがある（2026-11-25）

精妙二番で Sonnet を4票目として走らせたところ、1九 を「駒なし」とし、さらに**盤下に無い持駒
（銀・歩）を報告した**。盤面の升だけを聞いたプロンプトでも、持駒欄を「読んだ」と錯覚して
値を埋めることがある。

したがって第3・第4のモデルは:

- **持駒は必ず原寸で別確認**する（モデルの申告を信用しない）。
- 1升だけの判定に使うときも、その頁の他の升が既知の値と一致することを確認してから票を数える。

精妙二番の 1九 は p / +b / +R / なし の4者4様で、多数決は成立しない（`?` 維持）。

### 3モデル目を使うときの手順（2026-11-25）

1. **左右を合わせる**: 盤面は `source.page` の「右」「左」と一致させる。左盤を読ませて
   右盤の題に票を入れると、**別の題の盤面**を読むことになる（実際に精妙二番でこれをやり、
   隣の三番を読んでいた。票は捨てた）。
2. **持駒を突合**: モデルの申告した持駒が draft と一致するか確認する。一致しなければ
   その読みは捨てる（Sonnet は精妙二番で存在しない持駒を作った）。
3. **既知の升を突合**: 玉の位置と、争点以外の升が draft と合うか確認する。
4. **争点の票を数える**: 2対1 なら採用、3者3様なら保留。

精妙六番の 9二 は 銀/飛/金 の3者3様で保留。精妙三番の 3一 は +r が2票（既存1＋Sonnet）で採用した。

### 第3モデルの実績（2026-11-25 時点）

| 題 | 争点 | 票 | 結果 |
|---|---|---|---|
| 精妙 三 | 3一 | +r（既存1＋Sonnet） | **採用**（2票） |
| 精妙 二 | 1九 | p / +b / +R / なし | 保留（4者4様） |
| 精妙 六 | 9二 | 銀 / 飛 / 金 | 保留（3者3様） |
| 精妙 八 | 4四 | 金 / 龍 / 成銀 | 保留（3者3様） |
| 精妙 十 | 8九 | と / 金 / 歩 | 保留（3者3様） |

5題中、決まったのは1題だけ。**Sonnet は既存2票のどちらかと一致するより、第3の答えを出す
ことが多い**（4回中3回）。字形が本当に曖昧な升では、モデルを増やしても決まらない。

一方、Sonnet の読みは持駒・玉・既知の升がほぼ一致しており（10/11, 14/15 升）、
**読みの質は高いが争点だけが読めない**という状態。これは人間の目でも難しい升である可能性が
高く、原本の高精細画像か別の頁（同じ題の別の図）が必要。

### 争点の升は「解像度の限界」にある（2026-11-25）

精妙六番の 9二（銀/飛/金で3者3様）を、頁の 10%（横1200px）で切り出して目視した。

- 同じ段の既知の升（9一桂・8一桂・6一飛・8二玉・7二角）は**はっきり読める**。
- 9二 の字だけが崩れており、**銀（金＋艮）とも飛とも言い切れない**。ループ状の崩しで、
  金の草書か と のようにも見える。
- 同じ頁の 4二 の と（既知）と比べても、線の数が合わない。

原因は解像度: NDL の原画像はこのコマで約2000px幅、1升あたり約100×130px。争点の升は
その中で最も崩れた字で、**これ以上拡大しても情報は増えない**（補間で滑らかになるだけ）。

したがって、この種の升は:

1. 原本（紙）を見る、または
2. NDL により高解像度のコマがあればそれを使う、または
3. 同じ題の別の図（本編と詰手で盤面が再掲されている場合）と突き合わせる

のいずれかが必要。モデルを増やす・拡大するでは解決しない。

### 盤面の升は「詰手の列の 同X」で確定できる（2026-11-25・精妙六番）

9二 の字は4モデルで 銀 / 飛 / 金 / と に割れ、字形からは決まらなかった。
決めたのは**その題の詰手列**である。

- PID:861217 R0000003左 の六番列は「三九銀打・同金・三七金・同桂・一八角成…」で始まる。
- 2手目 同金 は、9三に打った銀を**金**で取る手。後手の金は9四にあり、9三へ届く金は
  9二しかない（8三は原寸で歩と確認）。→ **9二 = 後手金**。
- 盤面再生で 1〜5手がすべて成立（先手の各手が王手、5手目で後手の合法手なし＝詰み）。
- 詰み証明器も同じ盤面で5手詰を独立に発見し、7手探索では 銀打93（＝列頭）も強制手に入る。
  つまり盤面・列頭・列の先頭5手が三者で一致する。

**一般則**: 升の字が読めないときは、その題の詰手列の「同X」を探す。X が盤上のどこから
その升へ届くかは、多くの場合ひとつに決まる。字形（モデルの票）より強い証拠になる。

**この事例の留保**: 列は 角成 の後も「同龍…」と続くが、この盤面では5手で詰むので
続かない。後半は変化手順か、隣の題の列の混在とみられる（`docs/open-issues.json`
seimyo-006）。列の途中までを採用し、後半は採用しない、という切り分けをした。

### 傾いた頁は「墨の塊の重心」から升を取る（2026-11-25・貫珠五十番）

罫線の自動検出は、傾いた頁（貫珠五十番）で1升ぶんずれた。そこで:

1. 頁の領域を取り、インクの連結成分（墨の塊）を出す（scipy.ndimage.label）。
2. 塊の重心を既知の升に割り当てる。既知の駒（例: 7四の香）で較正を検算する。
3. 読みたい升の**重心を中心に** ±2〜3% を切り出す。罫線に頼らないので、傾きの影響を受けない。

この方法で貫珠五十番の3段目を読み直し、3升の誤りを訂正した:

| 升 | 旧 | 新 | 根拠 |
|---|---|---|---|
| 8三 | +N（圭） | **+P（と）** | 字が小さく幅広の と |
| 7三 | P（歩） | **N（桂）** | 木＋圭。同筋4段目の 香（既知）で列を検算 |
| 6三 | 空 | **P（歩）** | 明瞭な 歩 |

7三が桂になったことで**7筋の二歩が解消**。さらに 2二 の字は金ではなく、材数から
**杏（成香）** と確定（龍にすると後手飛が2枚になり不可能。杏なら 香4・金4・桂4・銀4 が揃う）。
結果、貫珠五十番の規則違反（二歩＋金5）は両方消えた。

**教訓**: 罫線検出より墨の塊の方が頑健。ただし罫線に触れた字は塊が巨大成分に融合して
消えるので、既知の駒で較正を検算し、取りこぼしを疑うこと。
