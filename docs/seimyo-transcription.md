## 転記の規則

1. 推測補完はしない。判読できない升は `?` のまま残す。
2. 先後の判定は「死駒禁則」だけを用いる（向き・印刷の天地に依存しない）。
   - 一段目（a段）の生歩・生香は先手なら動けず死駒 → 玉方（`p`/`l`）。
   - 九段目（i段）の生歩・生香は玉方なら死駒 → 先手（`P`/`L`）。
   - 一段目・二段目の生桂は先手なら死駒 → 玉方（`n`）。八段目・九段目の生桂は玉方なら死駒 → 先手（`N`）。
3. 駒数制約を併用する。香・桂は先後各1枚（盤上2枚が上限）なので、候補が上限に
   収まる場合のみ死駒禁則で先後を確定する。上限を超える場合の裁定は次のとおり
   （二十九番以降の台帳で採用した運用）。
   - 香/歩の混同候補が死段（a段・i段）にある升は、既存の歩裁定を適用して `p`/`P` とし、
     死段外の混同候補は `?` のまま残す（例: 二十九番・四十五番・五十四番・七十番）。
   - 桂の混同候補、および香/桂以外の密字形は `?` のまま残す。
   - 持駒の枚数が片側の全数を占める場合、盤上の同種駒の先後を消去法で確定できる
     （例: 五十三番・六十九番・七十九番・九十二番・九十五番・九十九番）。
4. 玉は常に玉方 `k`。攻方玉の表記は使わない。
5. 持駒は盤下の印刷を画像の左→右の順に読み、SFEN の駒種順（飛角金銀桂香歩）に並べ替える。
6. 読み取りは自分の NDL 画像読取を主とし、判読に迷う図は `codex exec -m gpt-6.1-terra -s read-only -i <jpg>...`
   に委託して突き合わせる。両者が一致した升だけを確定扱いにし、不一致は `?` とする。
