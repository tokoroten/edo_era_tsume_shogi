# 盤面の食い違い（原寸再読が必要な題）

作成: 2026-11-25。`?` の埋め残しとは別に、**印刷された盤面と draft の駒の並びが
構造的に食い違う**題を記録する。1升ずつの読み直しでは直らず、段・筋をまとめて
読み直す必要がある。証拠はすべて原寸切出（1升 ≒ 130x180px）と罫線の較正
（`tools/board_fit.py`）による。

## 判定のしかた

1. `python tools/board_fit.py <pid> <rid> "pct:x,y,w,h" 1400` で罫線を当てる。
2. 盤面を上下2帯（1700px 幅）で切り出し、段ごとに駒の**並び**を読む。
3. draft の同じ段と比べる。1筋ずれなら「同じ並びがずれて見える」はずで、
   **駒種が違うなら読み違い**、**駒数が違うなら欠落**と判断する。
