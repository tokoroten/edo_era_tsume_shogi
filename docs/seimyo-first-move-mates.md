## 十二番の追試（2026-11-27）

記録の初手は 三八飛（SFEN の 8三）。しかし盤面には**先手の飛・龍が1枚も無い**
（4一 にあるのは後手龍）。持駒も歩だけなので、この初手は十二番の盤面では指せない。

- 頁 R0000012 は**1葉に十二番と十三番の2図**が並ぶ小さな図で、枠の実測が揺れやすい
  （注記の枠 x 50.47-79.63 / y 33.3-78.8 は升目と一致しない）。
- 初手 三八飛 が**隣の十三番の列**を指している可能性がある（列帰属の誤り）。
  十二番の盤面を確定するには、この葉の2図を別々に枠取りして読み直す必要がある。

同種の「先手にその駒が無い」10題（12・27・44・56・68・75・92・93・99・100）は、
初手の列帰属か盤面の駒欠落のどちらかを、1題ずつ切り分ける。
