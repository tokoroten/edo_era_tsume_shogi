# データ取得ポリシー（Data Policy）

本リポジトリにおける詰将棋データ（盤面・棋譜・画像およびそれらの転記）の
取得元に関する確定ポリシーを定める。
`CONTRIBUTING.md` および `docs/provenance.md` と併せて適用する。
本ポリシーと既存記述が矛盾する場合は本ポリシーが優先する。

## 1. 基本原則

- データ取得は**国が運営する機関のアーカイブのみ**を許可する。
  代表例：国立国会図書館（NDL）デジタルコレクション等の国営アーカイブ。
- **NDL一次資料からの直接読解・転記が原則**である。
  スキャン画像を人間が直接読み、盤面（SFEN）および手順（USI）を起こす。
- 出典の記録（`source.repository` / `source.identifier` / `source.page` /
  `source.url` 等）は必須とし、由来不明のデータは受け入れない。

## 2. 許可ソース一覧

- 国が運営する機関のアーカイブに限定する。
  - 例：国立国会図書館（NDL）デジタルコレクション
  - その他、国が運営する機関のアーカイブで、一次資料の原本スキャンを
    公開しているもの（該当する場合は `source.repository` に機関名を明記し、
    識別子・URLで特定可能にすること）
- 大学・公立図書館・私立機関・学会・団体等の資料は、国営でない限り
  本ポリシーでは許可しない。利用したい場合はポリシー改定の議論を経ること。

## 3. 禁止ソース類型

### 禁止1：個人サイト

以下のような個人サイトからの盤面・棋譜・画像の**取得・参照を禁止**する。
閲覧しての写し取り、タイピング補助としての利用、照合のための参照を含む。

- 類型：個人が運営する詰将棋・将棋サイト全般
- 例：wakwak、oohasi、open-tsume 等（例示であり、これらに限定されない）
- 対象物：盤面図、棋譜（KIF等）、画像、解答手順テキスト、その他記録化の根拠となる一切のデータ

### 禁止2：国が運営していない団体

日本将棋連盟等の、国が運営していない団体からの**データ取得を禁止**する。

- 類型：公益社団法人・一般社団法人・民間企業・NPO・愛好会等、国営でない一切の団体
- 例：日本将棋連盟（shogi.or.jp 等を含む。同ドメイン配下の記事・棋譜・画像・解説の一切）
- 対象物：盤面、棋譜、画像、解説文、生成図面等、データ化の根拠となる一切の素材

## 4. 許可・禁止の境界

- NDL等の国営アーカイブの一次資料スキャン以外のWebサイト・書籍・アプリは
  スクレイピング・転載・参照の対象外とする。
- 第三者KIFファイルや将棋サイトは、タイピング補助としての利用も含め使用しない。
- `verification.reference_urls` 等に個人サイト・非政府団体のURLを記録しない。
- NDL一次資料の書誌情報（タイトル・請求記号・BibID・ページ等）を特定するための
  国営アーカイブ内の検索・目録ページの利用は妨げない。
  ただし盤面・手順の実体は必ず一次資料スキャンから直接読むこと。

## 5. 違反時の対処

1. **PR・Issue段階**：禁止ソース由来または由来不明のデータを含む提案は却下する。
   CIの provenance check 等で検出された場合も同様とする。
2. **混入発覚時**：該当レコードは `verification.needs_manual_review: true` に戻し、
   NDL一次資料からの再照合が完了するまで collated とみなさない。
   再照合不能な場合は該当レコード・該当部分を削除する。
3. **修正方法**：原本（`sfen`）の直接書き換えは行わない。
   運用は `CONTRIBUTING.md` および `docs/provenance.md` の訂正手順に従う
   （`corrected_sfen` + `correction_note` 等）。
4. **報告**：違反の疑いがある場合は、根拠（URL・ファイル・コミット等）を添えて
   Issue / PR レビューで報告する。判断に迷う取得元は事前に相談すること。
