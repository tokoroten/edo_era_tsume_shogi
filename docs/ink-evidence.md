### 精妙8 の 7四: 2400px でも決まらない（格子が1筋ずれているため）

高倍率（1600〜2400px）で 7四 を切ると、**升の中は空白**に見える。しかし同じ段を
横に並べると、印字の駒は**1筋ずれた位置**に現れる（例: draft が 8四 を空とする升に
駒がある）。この頁はインク照合でも「1筋にインクが集中」で棄却されており、
**格子が1筋ずれている**ことは既知。

したがって、この頁の升を座標で指定して読むことはできない。
7四 を決めるには、まず格子を直す（四隅ワープ）必要がある。
**2400px にすれば読める、というわけではない**（解像度ではなく格子の問題）。

### 精妙8 7四 は「龍」と判明（四隅ワープ・2026-11-25）

格子が1筋ずれていたので四隅を目測して `board_quad_sheet.py` で切り直すと、
升の境界が印字の罫線に一致し、盤面が読めた。

- **7四 の駒は 龍**（密な字形。隣の 6四 の 銀 とは別字）。draft の `?` は龍の読み落とし。
- 他の升は draft と一致（9一 王・8一 桂・7一 角・9三/8三 歩・9四 歩・6四 銀・6五 と・9六 銀・7七 桂・8九 香）。
- **側は未決**（先手玉が盤に無いため、初期王手の判定が使えない）。
- 材数は先手龍でも後手龍でも合法（飛は合計1枚）。

**重要な副産物**: この盤面で**王手になる初手は 7一の角→8二 の1手だけ**
（先手龍・後手龍のどちらでも同じ）。記録の列頭 一八角成 は 8一 への手で、
角は 7一 から 8一 へは行けない。したがって列頭の2字目は **二**（二八角成/八二角成）の
可能性が高い。ただし印字を読んでいないのでデータは変更しない。

### 精妙75 の `?` 2升（1四・3八）は と ではない（2026-11-25）

正しい格子で 1四 と 3八 を切り出すと、**同じ字形が同じ向きで**出る。
同頁の と（5一・5三・7六 は正立、3六・6七 は倒立）とは明確に形が違う:

- と（正立）: 小さな「と」。と（倒立）: 「う」形。いずれも**長い横棒を持たない**。
- `?` の2升: **長い横棒が上にあり、その下に「3」形と閉じた輪**。

この字形は、この頁の崩し字で **馬**（角の成駒）を 180° 倒したもの と読める
（點4つ 灬 が横棒になり、日 が輪になる）。2升が同じ向きなので、
字形だけでは先後が決まらない。

**材数による消去**: 盤上には既に銀が4枚（6二の S と 8一・7二・9五の s）。
成銀（全）にすると5・6枚目になり**上限4枚を超える**ので、全 はあり得ない。
一方 馬 は0枚なので2枚でも上限内、杏（成香）も0枚なので上限内。
字形（閉じた輪の中に横画がある＝日）から **馬** を第一候補、杏 を次点とする。

**機械探索**: 1四=+B/3八=+b とその入れ替えの両方を詰探索（9手・40万節）に
かけたが、どちらも MATE にならない（REFUTED）。したがって探索は先後の
決め手にならない。**データは `?` のまま**（推測で埋めない）。

### インクの重さだけでは と と成駒を分けられない（2026-11-25 訂正）

貫珠41 の 7二（`?`）は 0.30、同じ頁の既知の +p（5一）は 0.28。**と でも 0.30 に達する**。

| 頁 | 升 | インク | 字形の比較相手 | 結論 |
|---|---|---|---|---|

**貫珠30 の 6九 は従来「と 形」と記録されていたが、それは誤り**。字形は 龍 で、
