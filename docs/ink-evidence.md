## 貫珠30（金5枚）は、この頁では格子が合わず未解決（2026-11-25）

金5枚の題（貫珠30）で「どの金が成銀か」を字形で決めるため、R0000020 を測った。

- 剛体格子の整列度は **0.11**（床0.22未満）＝格子が合っていない。
- 原寸で盤の外枠を目測し `--cols 52.1,84.0 --rows 31.2,71.3` で切り直すと、
  **1段目だけは一致**（draft の f7=歩・f3=香 がインク 0.24/0.30）だが、
  2段目以下で合わない（例 2段の桂 f7 は 0.04）。
- したがってこの頁は**傾き/歪み**があり、5枚の金を正しい升で切り出せていない。
  前回の5枚比較（6四のみ金、他は空）も、この悪い格子に基づく**無効な観察**。

**結論（同日中に解決）**: 四隅ワープで作った升シートを3倍で比較すると、6四 は内側に2画のある 金、**5四 は屋根＋王で内側の画がない 全（成銀）**。5四 を成銀として採用し、材数違反は解消した。

### 貫珠30 の 6九 は、9段目が切れて読めない（2026-11-25）

同じ四隅ワープで 9段目（8九・6九・4九）を3倍で切ると、**4九 は 歩 で draft と一致**したが、
3升とも**下端が切れて**いた（盤の下端が升の底に重なる）。8九 の字は 金 とも 玉 とも
読め、6九 は判別できない。

- 「玉」と読むのは不可: 後手玉は既に 5二 にあり、2枚目の後手玉はありえない。
  したがって 8九 は 金（屋根が切れている）と考えるのが自然だが、確定はしない。
- **6九 は `?` のまま**。四隅の下端をさらに下げて再ワープするか、原本で読む。
- なお材数の修正（5四 = 成銀）は 4段目の升で行ったもので、9段目の読みとは独立。
