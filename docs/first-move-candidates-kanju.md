# 未検証の初手候補（kanju）

各題の玉に王手になる記録済み列頭。`（確定済み: N番）` は同じ手が
既に確定題の初手になっている列頭。1つの列頭は1題のものなので、
その列頭が未検証題の初手かは確定題との取り合いになる（複数番は
同じ手の題が複数あり、列頭の帰属が一意でないことを示す）。
候補が1つでも、その列頭が他の未検証題の候補にもなっていれば未決。
0なら列頭が未記録。

- **1**（Q=0, 玉5a）: 七五龍 R0000008 20.7-24.2（確定済み: 6番） / 三七角 R0000009 55.0-58.2（確定済み: 20番） / 二五銀成 R0000011 38.4-42.6（確定済み: 26番） / 五五龍 R0000013 66.5-69.9（確定済み: 33番）
- **5**（Q=20, 玉9b）: 一八銀 R0000007 81.3-85.5（確定済み: 13番） / 三九飛 R0000007 77.1-80.8 / 二八龍 R0000008 16.5-19.7（確定済み: 19番） / 六五角成 R0000013 80.1-83.0（確定済み: 32番） / 二二龍 R0000004 42.5-45.2（確定済み: 4番）
- **17**（Q=16, 玉9b）: 一八銀 R0000007 81.3-85.5（確定済み: 13番） / 三九飛 R0000007 77.1-80.8 / 二八龍 R0000008 16.5-19.7（確定済み: 19番） / 六五角成 R0000013 80.1-83.0（確定済み: 32番） / 二二龍 R0000004 42.5-45.2（確定済み: 4番）
