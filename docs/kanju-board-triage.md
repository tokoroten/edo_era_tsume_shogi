### 5.2 確かな判定法（? を含む盤面でも使える）

候補 SFEN の ? を空升として王手判定すると、

- **False は確定**（升を空と仮定して届かないなら、駒を足しても利きは伸びない）、
- **True は不確定**（? が実際は遮る駒かもしれない）。

この原理で再検査すると、#003 五一飛 / #009 六八龍 / #023 一八角 / #024 一三飛 /
#025 二九角 / #026 二五銀成 は**いずれも False＝初手として成立しない**（確定）。
一方 #007 一四飛 も False だったが、こちらは**列頭の読み違い**だった（下記）。

### 5.3 七番の解決: 一四飛 → 二四飛

PID 861192 R0000005 左頁 x 45.0-49.5% を 600px で切り出すと、小字は「二四」で
**二四飛**。4二に飛を置くと5二玉へ横王手（機械確認 True）、4一では False。
先手飛は盤上に無く持駒 R があるため打（印刷は「打」を省略）。
これで盤面 (q=0) を採用し、? を 14 減らした。

**教訓**: 列頭が王手にならないときは、盤面を疑う前に**列頭の小字を原寸で読み直す**。
600px 級の切出では 一/二/三 の判別が安定する。
