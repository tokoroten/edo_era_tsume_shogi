1000px 幅で頁を見ると1升22〜24pxだが、**原本から盤面領域を等倍近くで取れば85〜90px**あり、
活字の漢字なら読める。精妙で苦労した草書の と は、この2巻では**楷書に近い活字**なので有利。

## 手順（精妙・貫珠で確立した型）

1. 頁を1000pxで取得し、盤面の位置を概算する（左右どちらの頁かは draft の `source.page` を見る）。
2. 盤面領域を**幅800〜1100pxで取得**（原本の等倍前後）。
3. 罫線を走査して四隅を取る。この2巻は罫線が細く、閾値150程度で縦線は取れるが、
   **横線は駒の画と紛れる**ので、縦線の間隔から正方形を仮定して補う。
4. `tools/board_cell_ink.py` で升ごとのインクを出し、占有を確認。
5. 占有升を原寸で切り、**駒種と側**を読む。側は「正立＝先手／倒立＝後手」で判定。
6. SFEN を組み、`validate.py --draft` と `material_audit.py` を通す。
7. 持駒は盤下の「持駒」欄（例: 飛、角、銀）を読み、`hand_sheet.py` の発想で多重集合として照合。

## 注意（精妙で踏んだ穴）

- 盤の外枠と内側の格子が1升離れている頁がある。**四隅は内側の罫**で取る。
- 同じ見開きでも**右頁の題が先**の頁がある。`source.page` の左右を必ず確認する。
- 駒の字は**升の下半分**に寄る。升の中央で切ると上端が切れる。
- 側が読めない駒（と金など）は `?` のまま。材数の上限を超える読みは誤り。

## 最初に読む題

名人 8番（R0000009右）を試験に選んだ。盤面は頁の**中央やや右**、x 49〜69%、y 46〜77%。
罫線の走査では縦線が 22.5px 間隔（1000px幅）で取れた。横線は細く、駒と紛れるため
**縦線の間隔から正方形を仮定**して四隅を決めるのがよい。

この試験で、活字の駒（王・金・銀・桂・香・飛・角・歩）が読めることを確認済み。

## 試験の結果（名人8番・2026-11-26）

盤面の位置は頁の中央やや右（x 49〜69%、y 46〜77%）で、これは安定して取れる。
しかし**格子の自動決定は難航した**。分かったこと:

- 罫線は細く、**横線は駒の画と紛れて検出できない**（閾値150でも縦線のみ）。
- 縦線の間隔は 22.5px（1000px幅）前後だが、**外枠が格子の1升外側**にあるため、
  「一番外の線＝格子の端」とすると1升ぶん狂う（精妙87と同じ罠）。
- 駒の字は**升の下半分**に寄るので、升の中央で切ると上端が欠ける。

**結論**: この2巻を機械的に回すには、**縦横の罫線を低い閾値で拾い、等間隔の数列に
当てはめる道具**が要る（罫線の数列当てはめ道具 を試作したが、外枠と格子が離れた頁で
別解を選ぶことがあり、実用に至らなかった）。当面は、1題ずつ**外枠の内側の罫を目で確認**して
四隅を決める。1題あたり5〜8回の切出しを要する見込み。
