## 手順（精妙・貫珠で確立した型）

1. 頁を1000pxで取得し、盤面の位置を概算する（左右どちらの頁かは draft の `source.page` を見る）。
2. 盤面領域を**幅800〜1100pxで取得**（原本の等倍前後）。
3. 罫線を走査して四隅を取る。この2巻は罫線が細く、閾値150程度で縦線は取れるが、
   **横線は駒の画と紛れる**ので、縦線の間隔から正方形を仮定して補う。
4. `tools/board_cell_ink.py` で升ごとのインクを出し、占有を確認。
5. 占有升を原寸で切り、**駒種と側**を読む。側は「正立＝先手／倒立＝後手」で判定。
6. SFEN を組み、`validate.py --draft` と `material_audit.py` を通す。
7. 持駒は盤下の「持駒」欄（例: 飛、角、銀）を読み、`hand_sheet.py` の発想で多重集合として照合。

## 注意（精妙で踏んだ穴）

- 盤の外枠と内側の格子が1升離れている頁がある。**四隅は内側の罫**で取る。
- 同じ見開きでも**右頁の題が先**の頁がある。`source.page` の左右を必ず確認する。
- 駒の字は**升の下半分**に寄る。升の中央で切ると上端が切れる。
- 側が読めない駒（と金など）は `?` のまま。材数の上限を超える読みは誤り。

## 試験の結果（名人8番・2026-11-26）

盤面の位置は頁の中央やや右（x 49〜69%、y 46〜77%）で、これは安定して取れる。
しかし**格子の自動決定は難航した**。分かったこと:

- 罫線は細く、**横線は駒の画と紛れて検出できない**（閾値150でも縦線のみ）。
- 縦線の間隔は 22.5px（1000px幅）前後だが、**外枠が格子の1升外側**にあるため、

**10本の等差数列**に当てはめ、同点のときは**箱の一番外の線に固定しない**方を選ぶ
（＝外枠を避けて格子を取る）。合成画像のテスト付き。

## 駒の向きが頁と逆さま（2026-11-26 の発見）

名人8番の盤面を原寸で切ると、**駒の字が頁に対して180度回転している**。桂を例に取ると、
印刷されたままの形は「圭」が上・「木」が下で、**180度回すと正常な桂**になる。2-8 と 3-3 の
桂はどちらも同じ向き（＝どちらも回転している）。

これは次のどちらかを意味する。**盤面のSFENを組む前に、必ずどちらかへ決着させる必要がある。**

1. この2巻は**後手を正立・先手を倒立**で刷る（精妙・貫珠とは逆の慣習）。
2. この2巻は**盤面全体を後手側から見て刷る**（＝紙面の上下が SFEN の段と逆）。

**検証（同日・訂正）**: 盤面全体を180度回すと桂は正立になるが、**同じ段の銀と香は
頁のままでも正立**だった（名人8番の 2-2 銀・2-1 香）。つまり**盤面は回転しておらず**、
桂だけが倒立＝**その後手**を意味する。したがって **1 でも 2 でもなく、従来の規則と同じ**:
**正立＝先手／倒立＝後手**（精妙・貫珠と同一）。

桂を2枚（2-8・3-3）見て両方とも倒立だったため「全体が回転」と早合点したのが誤り。
同じ段に正立の銀・香があれば、盤面の回転ではなく駒ごとの向きだと分かる。
**教訓: 向きの判定は、同じ段に別種の駒を必ず1枚以上含めて行う。**

どちらでも「紙面の上＝1段」とは限らないため、**駒の利き（香・桂・歩の向き）と王の位置**から
判定する。精妙で使った「正立＝先手」の規則を、そのまま持ち込んではいけない。

### 決着の方法（次回）

- 香または歩が1枚だけ孤立している升を探し、**どちら向きに進むか**を字の向きで読む。
- 玉の位置と、詰将棋の初手が王手になる向き（攻方は玉に迫る側）を突き合わせる。
- 決まるまでは、大正2巻の SFEN は書かない（`?` のまま）。
